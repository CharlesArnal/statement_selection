# All Statements from Geometry of Manifolds I

1. **Theorem 5.1** (Inverse Function Theorem): If f: U -> W is smooth with invertible derivative at x, then f is a local diffeomorphism near x, and the derivative of the inverse is the inverse of the derivative.

2. **Theorem 5.2** (Implicit Function Theorem, submersion version): If f: U -> W is smooth with surjective derivative whose kernel admits a closed complement, then locally f can be written as a projection (up to diffeomorphisms of domain and codomain).

3. **Corollary 5.4** (Preimage of regular value): The preimage of a regular value is a submanifold.

4. **Lemma 6.1** (Lipschitz/C^1 properties of ODE flow): If the vector field X is K-Lipschitz then the associated ODE operator F: C^0 -> C^0 is also K-Lipschitz; if X is C^1 with uniformly bounded derivative then F is C^1.

5. **Theorem 10.1** (Vector bundle of finite type embeds): A vector bundle of finite type over M admits a classifying map f: M -> Gr_k(R^N) for N large enough.

6. **Theorem 11.1** (Whitney Embedding Theorem, Easiest Version): Any compact n-manifold admits an embedding in R^N for some large N.

7. **Theorem 12.1** (Fubini-type measure zero result): If a measurable set C in R^n has the property that every slice C cap ({t} x R^{n-1}) has measure zero, then C has measure zero.

8. **Lemma 12.2** (Continuous image of measurable set): If C in R^m is measurable and f: R^m -> R^n is continuous, then f(C) is measurable.

9. **Theorem 12.3** (Sard's Theorem): The set of critical values of a smooth map between finite-dimensional manifolds has measure zero.

10. **Proposition 13.2** (R_l is a submanifold): The set R_l of linear maps from R^k to R^n of rank l is a smooth submanifold of hom(R^k, R^n) of codimension (k-l)(n-l).

11. **Lemma 13.3** (Kernel characterization via block matrices): A kernel characterization for a matrix near an invertible block: (v,w) is in the kernel of B iff v = -(A_bar + alpha)^{-1} beta w and (delta - gamma(A_bar + alpha)^{-1} beta) v = 0.

12. **Theorem 15.1** (Whitney Embedding into R^{2n+1}): Any compact n-manifold admits an embedding in R^{2n+1}.

13. **Lemma 15.2** (Generic hyperplane projection is embedding): If N > 2n+1, then for a full measure set of hyperplanes the projection of M into the hyperplane is an embedding.

14. **Proposition 15.3** (Closed smooth n-manifold immerses into R^{2n}): If M is a closed smooth n-manifold then M immerses into R^{2n}.

15. **Theorem 16.3** (Completion of normed vector space): Every normed vector space has a unique completion as a Banach space with a canonical isometric embedding and universal property.

16. **Theorem 16.5** (Hahn-Banach Theorem): A linear functional bounded by a seminorm on a subspace can be extended to the whole space preserving the bound.

17. **Corollary 16.6** (Finite dim subspace has closed complement): A finite-dimensional subspace of a Banach space has a closed complementary subspace.

18. **Theorem 16.7** (Open Mapping Theorem): A surjective bounded linear map between Banach spaces is open.

19. **Theorem 16.8** (Banach Isomorphism Theorem): A bounded linear bijection between Banach spaces is a topological isomorphism.

20. **Theorem 16.9** (Closed Graph Theorem): A linear operator between Banach spaces is bounded if and only if its graph is closed.

21. **Theorem 16.11** (Arzela-Ascoli Theorem): A subset of C^0(B) has compact closure if and only if it is bounded and equicontinuous.

22. **Corollary 16.12** (C^1 to C^0 embedding is compact): The embedding C^1(B) -> C^0(B) is a compact operator.

23. **Lemma 16.14** (Range with closed complement is closed): If T: X -> Y is an operator whose range admits a closed complementary subspace, then the range of T is closed.

24. **Theorem 16.15** (Perturbation of invertible operators): If T: X -> Y is bounded invertible, then T + p is also invertible for p of sufficiently small norm (via Neumann series).

25. **Lemma 16.16** (Riesz Lemma): The unit ball in a Banach space X is compact if and only if X is finite-dimensional.

26. **Lemma 16.18** (Fredholm operators are open, index locally constant): The set of Fredholm operators Fred(X,Y) is open in B(X,Y) and the index is locally constant on it.

27. **Lemma 16.19** (Fredholm perturbation linear map): For a Fredholm operator T and small perturbation p, there is a linear map A: ker(T) -> Coker(T) such that ker(T+p) = ker(A) and Coker(T+p) = Coker(A).

28. **Lemma 16.20** (Fredholm map perturbation decomposition): A small perturbation of a Fredholm map can be conjugated into block diagonal form with identity and a finite-dimensional map.

29. **Lemma 16.22** (Adjoint has same norm): If T is bounded then T* is bounded with the same operator norm.

30. **Lemma 16.23** (Closed range and adjoint): If T has closed range then Coker(T)* is isomorphic to ker(T*).

31. **Lemma 16.24** (Compact operator has compact adjoint): If K: X -> Y is compact then K*: Y* -> X* is compact.

32. **Lemma 16.25** (I + compact is Fredholm): If K: X -> X is compact then I + K is a Fredholm operator.

33. **Theorem 16.26** (Fredholm iff has parametrix): T is Fredholm if and only if there exists R such that RT - I and TR - I are compact.

34. **Lemma 16.27** (Fredholm composition and index additivity): The composition of Fredholm operators is Fredholm and Ind(ST) = Ind(S) + Ind(T).

35. **Theorem 17.3** (Sard-Smale Theorem): For a smooth Fredholm map between second-countable Banach manifolds, the set of regular values is residual.

36. **Lemma 17.4** (Fredholm map local form): A Fredholm map can be locally written in the form (x, g(x,k)) after suitable coordinate changes.

37. **Lemma 17.6** (Fredholm map is locally closed): A Fredholm map f: X -> Y between Banach manifolds is locally closed.

38. **Lemma 18.2** (Transverse preimage is submanifold): If f: M -> N is transverse to a submanifold Z, then f^{-1}(Z) is a smooth submanifold of the expected dimension.

39. **Theorem 18.3** (Parametric Transversality, finite dim): If F: P x M -> N is a submersion and Z is a submanifold of N, then for generic p in P, f_p is transverse to Z.

40. **Lemma 18.4** (Transversality criterion via preimage): F^{-1}(Z) is transverse to {p} x M if and only if f_p is transverse to Z.

41. **Theorem 18.5** (Parametric Transversality, Banach Fredholm): If F: P x M -> N is a submersion with f_p Fredholm and Z finite-dimensional, then for a residual set of p, f_p is transverse to Z.

42. **Lemma 18.6** (Isomorphism related to transversality): An isomorphism between the cokernel of the projection and the cokernel of the map f_p relative to Z.

43. **Theorem 18.8** (Thom Transversality Theorem): The set of maps f: M -> N in C^k(M,N) transverse to a submanifold Z is residual.

44. **Theorem 19.1** (Whitney Embedding into R^{2n}, strong version): Any compact n-manifold admits an embedding into R^{2n} (Whitney 1944).

45. **Lemma 19.2** (Z_i is a submanifold): Z_i is a submanifold of Gr_n(R^{2n}) x Gr_n(R^{2n}) of dimension 2n^2 - i^2.

46. **Lemma 19.3** (Local chart form at double points): Near a transverse double point of an immersion, there is a specific local chart description.

47. **Proposition 19.4** (Whitney trick): A pair of double points of opposite sign can be eliminated without introducing new double points.

48. **Lemma 21.1** (Flow derivative formula): d/dt f(F_t(x))|_{t=0} = D_x f(X(x)), where F_t is the flow of vector field X.

49. **Theorem 21.3** (Flow box theorem / straightening lemma): Near a point where a vector field is nonzero, there exists a chart straightening the vector field to a constant field.

50. **Theorem 21.4** (Frobenius Theorem): An involutive subbundle of the tangent bundle is integrable.

51. **Proposition 22.1** (Normal vector field to foliation): For a codimension-one foliation with normal vector field n, we have n . (curl n) = 0.

52. **Theorem 24.2** (S^2 leaf implies S^2 x S^1): If a normally oriented two-dimensional foliation of a compact oriented 3-manifold contains S^2 as a leaf, then the manifold with its foliation is diffeomorphic to S^2 x S^1 with the product foliation.

53. **Lemma 24.3** (Foliating coordinate patch extension): An embedding of D^2 into a leaf of a foliation can be extended to a foliating coordinate patch D^2 x (-epsilon, epsilon).

54. **Lemma 24.4** (S^2 leaf has product neighborhood): A leaf diffeomorphic to S^2 in a foliation has a saturated neighborhood diffeomorphic to S^2 x (-a,a) with product foliation.

55. **Theorem 24.5** (Transverse circle to foliation exists): For a transversally oriented foliation, there exists a circle embedded transverse to the leaves through any point.

56. **Proposition 25.4** (Homotopy invariance of de Rham cohomology): H*(M) is isomorphic to H*(R x M).

57. **Lemma 27.1** (Mayer-Vietoris sequence exact for k > 0): The Cech complex with coefficients in the sheaf of differential forms is exact for k > 0.
