# All Statements from Measure and Integration

## Statement 1: Proposition 0.1 (Lecture 1)
Let X, Y, Z be topological spaces such that X -> f -> Y -> g -> Z.
(1) If f and g are continuous, then g o f is continuous.
(2) If f is measurable and g is continuous, then g o f is measurable.

## Statement 2: Theorem 0.2 (Lecture 1)
Let u: X -> R, v: X -> R, and Phi: R x R -> Y. Set h(x) = Phi(u(x), v(x)): X -> Y. If u and v are measurable and Phi is continuous, then h: X -> Y is measurable.

## Statement 3: Proposition 0.3 (Lecture 1)
Let F be any collection of subsets of X. Then there exists a smallest sigma-algebra M* such that F is contained in M*. We call M* the sigma-algebra generated by F.

## Statement 4: Proposition 0.1 (Lecture 2)
Let M be a sigma-algebra on X, let Y be a topological space, and let f: X -> Y.
(a) Let Omega be a collection of sets E subset Y such that f^{-1}(E) in M. Then Omega is a sigma-algebra on Y.
(b) If f is measurable and E subset Y is Borel, then f^{-1}(E) in M.
(c) If Y = [-inf, inf] and f^{-1}((alpha, inf]) in M for all alpha in [-inf, inf], then f is measurable.

## Statement 5: Proposition 0.2 (Lecture 2)
A sequence {a_n} converges if and only if lim inf a_n = lim sup a_n = lim a_n.

## Statement 6: Theorem 0.3 (Lecture 2)
If, for each i = 1, 2, ..., the function f_i: X -> [-inf, inf] is measurable, then g = sup_{i>=1} f_i and h = limsup_{n->inf} f_n are both measurable.

## Statement 7: Corollary 0.4 (Lecture 2)
(a) Pointwise limits of measurable functions are measurable.
(b) If f and g are measurable, then max{f,g} and min{f,g} are measurable.

## Statement 8: Theorem 0.5 (Lecture 2)
Let f: X -> [0, inf] be measurable. Then there exists a sequence 0 <= s_1 <= s_2 <= ... of measurable simple functions such that lim_{n->inf} s_n = f.

## Statement 9: Theorem 0.1 (Lecture 3)
A function f is Riemann integrable if and only if f is discontinuous on a set of measure zero.

## Statement 10: Theorem 0.2 (Lecture 3)
(1) If E subset R and mu(E) < inf, then mu(empty) = 0.
(2) (Monotonicity) A subset B => mu(A) <= mu(B).
(3) If A_i in M for i = 1, 2, ..., A_1 subset A_2 subset ..., and A = union_{i=1}^inf A_i, then mu(A_i) -> mu(A) as i -> inf.
(4) If A_i in M for i = 1, 2, ..., A_1 supset A_2 supset ..., mu(A_1) < inf, and A = intersection_{i=1}^inf A_i, then mu(A_i) -> mu(A) as i -> inf.

## Statement 11: Proposition 0.1 (Lecture 4)
Let s and t be non-negative measurable simple functions. Then integral_X (s+t) dmu = integral_X s dmu + integral_X t dmu.

## Statement 12: Theorem 0.2 (Lecture 4) - Monotone Convergence Theorem
Let f_n: X -> [0, inf] be a sequence of measurable functions such that (a) 0 <= f_1 <= f_2 <= ... <= inf, and (b) f_n(x) -> f(x) as n -> inf for all x in X. Then integral_X f_n dmu -> integral_X f dmu as n -> inf.

## Statement 13: Theorem 0.3 (Lecture 4)
Let f_n: X -> [0, inf] be a sequence of measurable functions and f(x) = sum_{n=1}^inf f_n(x). Then integral_X f dmu = sum_{n=1}^inf integral_X f_n dmu.

## Statement 14: Corollary 0.4 (Lecture 4)
Let X = Z+ and mu be the counting measure. Let a_{ij} >= 0. Then sum_{i=1}^inf sum_{j=1}^inf a_{ij} = sum_{j=1}^inf sum_{i=1}^inf a_{ij}.

## Statement 15: Lemma 0.5 (Lecture 4) - Fatou's Lemma
Let f_n: X -> [0, inf] be a sequence of measurable functions. Then integral_X (liminf_{n->inf} f_n) dmu <= liminf_{n->inf} integral_X f_n dmu.

## Statement 16: Theorem 0.1 (Lecture 5) - Linearity of the Integral
Let f, g in L^1(mu). If alpha, beta in C, then alpha f + beta g in L^1(mu) and integral_X (alpha f + beta g) dmu = alpha integral_X f dmu + beta integral_X g dmu.

## Statement 17: Theorem 0.2 (Lecture 5)
If f in L^1(mu), then |integral_X f dmu| <= integral_X |f| dmu.

## Statement 18: Theorem 0.3 (Lecture 5) - Dominated Convergence Theorem
Let f_n: X -> C be a sequence of measurable functions, and assume that f(x) = lim_{n->inf} f_n(x) (pointwise convergence). If there exists g in L^1(mu) such that |f_n(x)| <= g(x) for all n and for all x in X, then f in L^1(mu) and lim_{n->inf} integral_X |f_n - f| dmu = 0, so lim_{n->inf} integral_X f_n dmu = integral_X f dmu.

## Statement 19: Proposition 0.4 (Lecture 5)
If f ~ g (f = g a.e.), then, for all E in M, integral_E f dmu = integral_E g dmu.

## Statement 20: Theorem 0.5 (Lecture 5) - Completion of a sigma-algebra
Let (X, M, mu) be a measure space. Let M* = { E subset X | there exist A, B in M: A subset E subset B & mu(B \ A) = 0 }. Now define mu(E) = mu(A) for all E in M*. Then M* is a sigma-algebra and this definition of mu is a measure.

## Statement 21: Theorem 0.6 (Lecture 5)
(a) Let f: X -> [0, inf] be measurable, E in M, and integral_E f dmu = 0. Then f = 0 a.e. on E.
(b) Let f in L^1(mu) and integral_E f dmu = 0 for every E in M. Then f = 0 a.e. on X.

## Statement 22: Theorem 0.7 (Lecture 5)
Let E_k in M such that sum_{k=1}^inf mu(E_k) < inf. Then almost every x in X lies in at most finitely many E_k.

## Statement 23: Lemma 0.1 (Lecture 7)
Let A, B in L_0. If A and B are disjoint, then A union B in L_0 and lambda(A union B) = lambda(A) + lambda(B).

## Statement 24: Theorem 0.2 (Lecture 7) - Main Approximation Theorem
Let A in R^n and lambda*(A) < inf. Then A in L_0 if and only if for all epsilon > 0 there exists K compact and G open such that K subset A subset G and lambda(G \ K) < epsilon.

## Statement 25: Corollary 0.3 (Lecture 7)
If A, B in L_0, then A union B, A intersection B, and A \ B are all in L_0.

## Statement 26: Corollary 0.5 (Lecture 7)
L is a sigma-algebra.

## Statement 27: Corollary 0.6 (Lecture 7)
lambda is a positive measure on L, and thus (R^n, L, lambda) is a measure space.

## Statement 28: Proposition 0.4 (Lecture 7)
The new lambda is consistent with all lambda when lambda* < inf. In other words, if A subset R^n and lambda(A) < inf, then A in L_0 iff A in L, and the definitions of lambda(A) agree.

## Statement 29: Corollary 0.1 (Lecture 9)
If A subset R^n is measurable with positive measure, then there exists B subset A that is not measurable.

## Statement 30: Theorem 0.2 (Lecture 9) - Invariance under linear transformations
Let T: R^n -> R^n be a linear map and A subset R^n. Then lambda*(TA) = |det T| lambda*(A), lambda_*(TA) = |det T| lambda_*(A). If A is measurable, then TA is measurable and lambda(TA) = |det T| lambda(A).

## Statement 31: Lemma 0.3 (Lecture 9)
Let T be invertible and let J = [0,1)^n. Let rho be defined by lambda(TJ) = rho lambda(J). If A subset R^n, then lambda*(TA) = rho lambda*(A) and lambda_*(TA) = rho lambda_*(A). If A is measurable, then TA is measurable and lambda(TA) = rho lambda(A).

## Statement 32: Theorem 0.1 (Lecture 10) - Riesz Representation Theorem
Let X be a locally compact Hausdorff space. Let Lambda: C_c(X) -> C be a positive linear functional. Then there exists a sigma-algebra M in X which contains all the Borel sets and a unique positive measure mu on M such that:
(a) Lambda f = integral_X f dmu for all f in C_c(X).
(b) mu(K) < inf for all compact sets K subset X.
(c) If E in M, then mu(E) = inf{mu(V) | E subset V, V open}.
(d) If E is open or E in M with mu(E) < inf, then mu(E) = sup{mu(K) | K subset E, K compact}.
(e) If E in M, A subset E, and mu(E) = 0, then A in M.

## Statement 33: Theorem 0.1 (Lecture 11) - Lusin's Theorem
Let f: X -> R (or C) be a measurable function on a locally compact Hausdorff space X. Let A subset X, mu(A) < inf, and f(x) = 0 if x not in A. Given epsilon > 0, there exists g in C_c(X) such that mu({x | f(x) != g(x)}) < epsilon.

## Statement 34: Corollary 0.2 (Lecture 11)
Let f: X -> R, A subset X, mu(A) < inf, f(x) = 0 if x not in A, and |f(x)| < M for some M < inf. Then there exists a sequence g_n in C_c(X) such that |g_n(x)| < M and f(x) = lim_{n->inf} g_n(x) almost everywhere.

## Statement 35: Theorem 0.3 (Lecture 11) - Vitali-Caratheodory Theorem
Let f: X -> R and f in L^1(mu). Given epsilon > 0, there exist functions u, v: X -> R such that u <= f <= v, u is upper semicontinuous, v is lower semicontinuous, and integral (v - u) dmu < epsilon.

## Statement 36: Theorem 0.1 (Lecture 12) - LDCT for a.e. convergence
Let f_1, f_2, ...: X -> C be a sequence of measurable functions defined a.e. Let g: X -> C be defined almost everywhere and g in L^1(mu). Assume lim_{k->inf} f_k(x) exists for a.e. x in X and |f_k(x)| <= |g(x)| for a.e. x in X. Then integral_X (lim_{k->inf} f_k) dmu = lim_{k->inf} integral_X f_k dmu.

## Statement 37: Theorem 0.2 (Lecture 12)
Let f_1, f_2, ...: X -> C with each f_k in L^1(mu) and assume that sum_{k=1}^inf integral_X |f_k| dmu < inf. Then sum_{k=1}^inf f_k exists a.e. and integral_X (sum_{k=1}^inf f_k) dmu = sum_{k=1}^inf integral_X f_k dmu.

## Statement 38: Theorem 0.1 (Lecture 13) - Egoroff's Theorem
Suppose mu(X) < inf. Let f_n: X -> C be a sequence of measurable functions such that f_n -> f a.e. For all epsilon > 0, there exists a measurable subset E subset X with mu(X \ E) < epsilon and such that f_n -> f uniformly on E.

## Statement 39: Theorem 0.2 (Lecture 13)
If f_n -> f a.e. and mu(X) < inf, then f_n -> f in measure.

## Statement 40: Theorem 0.3 (Lecture 13)
If f_n -> f in measure, then f_n has a subsequence f_{n_k} such that lim_{k->inf} f_{n_k} = f a.e.

## Statement 41: Theorem 0.4 (Lecture 13) - DCT for convergence in measure
Let f_n: X -> C be a sequence of measurable functions defined a.e. Suppose f_n -> f in measure and |f_n| <= |g| a.e. with g in L^1(mu). Then integral_X f dmu = lim_{n->inf} integral_X f_n dmu.

## Statement 42: Lemma 0.5 (Lecture 13)
Let a_n be a sequence. If every subsequence has a subsequence which converges to alpha, then lim_{n->inf} a_n = alpha.

## Statement 43: Theorem 0.1 (Lecture 14) - Continuity of convex functions
If phi is convex on (a,b), then phi is continuous on (a,b).

## Statement 44: Jensen's Inequality (Lecture 14)
Let (Omega, M, mu) be a measure space such that mu(Omega) = 1. Let f: Omega -> R and f in L^1(mu). If a < f(x) < b for all x in Omega and phi is convex on (a,b), then phi(integral_Omega f dmu) <= integral_Omega (phi o f) dmu.

## Statement 45: Theorem 0.2 (Lecture 14) - Holder's and Minkowski's Inequalities
Let p and q be conjugate exponents with 1 < p < inf. Let (X, M, mu) be a measure space and f, g: X -> [0, inf] measurable functions. Then
(Holder's) integral_X fg dmu <= (integral_X f^p dmu)^{1/p} (integral_X g^q dmu)^{1/q}
and
(Minkowski's) (integral_X (f+g)^p dmu)^{1/p} <= (integral_X f^p dmu)^{1/p} + (integral_X g^p dmu)^{1/p}.

## Statement 46: Proposition 0.1 (Lecture 15)
If f in L^inf, then |f(x)| <= ||f||_inf a.e.

## Statement 47: Theorem 0.2 (Lecture 15) - Holder's inequality for L^p
Let 1 <= p <= inf and 1/p + 1/q = 1. Let f in L^p(mu) and g in L^q(mu). Then fg in L^1(mu) and ||fg||_1 <= ||f||_p ||g||_q.

## Statement 48: Theorem 0.3 (Lecture 15) - Minkowski's inequality (triangle inequality for L^p)
Let 1 <= p <= inf. Let f, g in L^p(mu). Then f + g in L^p(mu) and ||f + g||_p <= ||f||_p + ||g||_p.

## Statement 49: Lemma 0.4 (Lecture 15)
If {f_n} is Cauchy, then there exists a subsequence f_{n_k} such that d(f_{n_{k+1}}, f_{n_k}) <= 2^{-k}.

## Statement 50: Theorem 0.5 (Lecture 15) - Riesz-Fischer Theorem
For 1 <= p <= inf and for any measure space (X, M, mu), the space L^p(mu) is a Banach space.

## Statement 51: Theorem 0.6 (Lecture 15)
Let 1 <= p <= inf and {f_n} be a Cauchy sequence in L^p(mu) such that ||f - f_n||_p -> 0. Then f_n has a subsequence which converges pointwise almost everywhere to f(x).

## Statement 52: Theorem 0.1 (Lecture 16) - Simple functions dense in L^p
Let S = {s: X -> C | s simple, measurable such that mu({x | s(x) != 0}) < inf}. For 1 <= p < inf, S is dense in L^p(mu).

## Statement 53: Corollary 0.2 (Lecture 16) - C_c dense in L^p
If X is a locally compact Hausdorff space, then for 1 <= p < inf, C_c(X) is dense in L^p.

## Statement 54: Theorem 0.3 (Lecture 16) - Completion of C_c under sup norm
The completion of C_c(X) under ||.||_inf is C_0(X).

## Statement 55: Theorem 0.1 (Lecture 17) - Limit of L^p norms
Let f in L^r for some r < inf. Then lim_{p->inf} ||f||_p = ||f||_inf.

## Statement 56: Theorem 0.2 (Lecture 17) - Inclusion for finite measure spaces
If 1 <= p < q < inf and mu(X) < inf, then L^q subset L^p.

## Statement 57: Theorem 0.3 (Lecture 17) - Inclusion for l^p spaces
If 1 <= p < q <= inf, then l^p subset l^q, and ||f||_inf <= ||f||_q <= ||f||_p <= ||f||_1.

## Statement 58: Theorem 0.4 (Lecture 17) - Convexity of L^p norm (interpolation)
Let 1 <= p < r < q < inf and suppose f in L^p intersection L^q. Then f in L^r and log ||f||_r <= theta log ||f||_p + (1-theta) log ||f||_q, where 1/r = theta/p + (1-theta)/q.

## Statement 59: Theorem 0.1 (Lecture 18) - Fubini I (non-negative functions)
Assume that f: R^n -> [0, inf] is L-measurable. Then for a.e. y in R^m, the function f_y: R^l -> [0, inf] is L-measurable, and F(y) = integral_{R^l} f_y(x) dx exists. Moreover, F is L-measurable on R^m, and integral_{R^m} F(y) dy = integral_{R^n} f(z) dz.

## Statement 60: Theorem 0.2 (Lecture 18) - Fubini II (integrable functions)
Assume that f in L^1(R^n). Then for a.e. y in R^m, the function f_y in L^1(R^l), and F(y) = integral_{R^l} f_y(x) dx exists. Moreover, F in L^1(R^m), and integral_{R^m} F(y) dy = integral_{R^n} f(z) dz.

## Statement 61: Proposition 0.1 (Lecture 19)
Let R^n = R^l x R^m. Let X subset R^l be L^l-measurable and Y subset R^m be L^m-measurable. Then X x Y subset R^n is L^n-measurable, and lambda(X x Y) = lambda(X) lambda(Y).

## Statement 62: Proposition 0.2 (Lecture 19)
If E in M_X x M_Y, then E_y (the x-section of E at y) is in M_X for all y in Y.

## Statement 63: Proposition 0.3 (Lecture 19)
If E in M_X x M_Y, then E_y in M_X for all y and lambda(E_y) is a measurable function on Y.

## Statement 64: Proposition 0.4 (Lecture 19)
Let f: X x Y -> C be M_X x M_Y-measurable. Then (a) for every x in X, f_x: Y -> C is M_Y-measurable, (b) for every y in Y, f_y: X -> C is M_X-measurable.

## Statement 65: Theorem 0.5 (Lecture 19)
Let R^n = R^l x R^m. Then L^n is the completion of L^l x L^m.

## Statement 66: Theorem 0.1 (Lecture 20) - Convolution in L^1
Assume f, g in L^1(R^n). Then for a.e. x in R^n, the convolution (f * g)(x) exists, f * g in L^1(R^n), and ||f * g||_1 <= ||f||_1 ||g||_1.

## Statement 67: Theorem 0.2 (Lecture 20) - Young's Inequality
Let p, q, r in [1, inf] such that 1/r = 1/p + 1/q - 1. If f in L^p(R^n) and g in L^q(R^n), then f * g exists a.e. and f * g in L^r(R^n). Moreover, ||f * g||_r <= ||f||_p ||g||_q.

## Statement 68: Theorem 0.3 (Lecture 20)
Let 1 <= p <= inf and f in L^p(R^n). Then the integral defining (f*g)(x) exists for all x in R^n, f*g is bounded and uniformly continuous, and if 1 < p < inf, then f*g in C_0.

## Statement 69: Theorem 0.4 (Lecture 21) - C_c^inf dense in L^p
C_c^inf is dense in L^p.

## Statement 70: Lemma 0.5 (Lecture 21)
If f in L^1(R^n), then lim_{y->0} integral_{R^n} |f(x+y) - f(x)| dx = 0.

## Statement 71: Theorem 0.6 (Lecture 21) - Approximation by mollifiers
Let f in L^p(R^n) with 1 <= p < inf. Then lim_{a->0} ||f * phi_a - f||_p = 0.

## Statement 72: Theorem 0.1 (Lecture 22) - Absolute continuity and FTOC
If f is absolutely continuous, then f is differentiable a.e. and f' in L^1. In particular, the second half of the FTOC holds.

## Statement 73: Theorem 0.2 (Lecture 22) - Vitali Covering Theorem
Let E subset R^n be a bounded set, and suppose we have a collection of balls F containing E such that every point of E is at the center of some ball. Then there exist balls B_1, B_2, ... in F so that (1) B_1, B_2, ... are disjoint, and (2) E subset union_{alpha>=1} 3B_alpha.

## Statement 74: Theorem 0.3 (Lecture 22) - Hardy-Littlewood Maximal Inequality
If f in L^1(R^n), then lambda({x | Mf(x) > t}) <= 3^n ||f||_1 / t for all 0 < t < inf, i.e., Mf is weak (1,1).

## Statement 75: Theorem 0.1 (Lecture 23) - Lebesgue Differentiation Theorem
Let f in L^1(R^n). Then for almost every x in R^n, lim_{r->0} (1/lambda(B(x,r))) integral_{B(x,r)} |f(y) - f(x)| dy = 0. In particular, for a.e. x in R^n, lim_{r->0} (1/lambda(B(x,r))) integral_{B(x,r)} f(y) dy = f(x).

## Statement 76: Theorem 0.2 (Lecture 23)
Let f in L^1(R^n), x in the Lebesgue set of f, and E_1, E_2, ... converge regularly to x. Then f(x) = lim_{k->inf} (1/lambda(E_k)) integral_{E_k} f(y) dy.

## Statement 77: Theorem 0.3 (Lecture 23) - FTOC II
Let f in L^1(R) and let a in R. Define F(x) = integral_a^x f(y) dy. Then F is differentiable a.e. and F' = f a.e.

## Statement 78: Theorem 0.1 (Lecture 24) - Distribution functions
integral_X f dmu = integral_0^inf mu{f > t} dt and integral_X f^p dmu = p integral_0^inf mu{f > t} t^{p-1} dt. More generally, if phi is differentiable, then integral_X phi o f dmu = integral_0^inf mu{f > t} phi'(t) dt.

## Statement 79: Theorem 0.2 (Lecture 24) - Marcinkiewicz interpolation for maximal function
Let 1 < p < inf and f in L^p. Then Mf in L^p, and ||Mf||_p <= C(n,p) ||f||_p.
