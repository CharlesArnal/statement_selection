## Chapter 2: The Category of Sets

1. **Notation 2.1.1.1.** The symbol $\emptyset$ denotes the set with no elements. The symbol $\mathbb{N}$ denotes the set of natural numbers.

2. **Lemma 2.1.2.12.** The following facts hold about isomorphism: (a) Reflexivity: for every set A there is an isomorphism A ≅ A. (b) Symmetry: for any sets A and B, if A ≅ B then B ≅ A. (c) Transitivity: for any sets A, B, C, if A ≅ B and B ≅ C then A ≅ C.

3. **Definition 2.1.2.16.** Cardinality of finite sets. The cardinality of a finite set A, denoted |A|, is the natural number n such that A ≅ {1, 2, ..., n}.

4. **Lemma 2.1.2.18.** Let A and B be finite sets. If there is an isomorphism of sets f: A → B then the two sets have the same cardinality, |A| = |B|.

5. **Definition 2.4.1.1.** Let X and Y be sets. The product of X and Y, denoted X × Y, is defined as the set of ordered pairs (x, y) where x ∈ X and y ∈ Y.

6. **Lemma 2.4.1.10** (Universal property for product). Let X and Y be sets. For any set A and functions f: A → X and g: A → Y, there exists a unique function A → X × Y making the relevant diagrams commute.

7. **Definition 2.4.2.1.** Let X and Y be sets. The coproduct of X and Y, denoted X ⊔ Y, is defined as the disjoint union of X and Y.

8. **Lemma 2.4.2.7** (Universal property for coproduct). Let X and Y be sets. For any set A and functions f: X → A and g: Y → A, there exists a unique function X ⊔ Y → A making the relevant diagrams commute.

9. **Definition 2.5.1.1** (Pullback). The fiber product of sets X and Y over a set B via functions f: X → B and g: Y → B is X ×_B Y := {(x, y) ∈ X × Y | f(x) = g(y)}.

10. **Definition 2.5.1.12** (Preimage). Let f: X → Y be a function and y ∈ Y an element. The preimage of y under f is f⁻¹(y) := {x ∈ X | f(x) = y}.

11. **Lemma 2.5.1.14** (Universal property for pullback). For any set A with functions to X and Y that agree when composed to B, there exists a unique function A → X ×_B Y making everything commute.

12. **Proposition 2.5.1.17.** The pullback of a monomorphism is a monomorphism.

13. **Definition 2.5.2.1.** Given sets A and B, a span on A and B is a set R together with functions f: R → A and g: R → B.

14. **Definition 2.5.2.3.** Let A, B, and C be sets, and let spans on A,B and B,C be given. Their composite span is given by the fiber product R ×_B R'.

15. **Definition 2.5.3.1.** The equalizer of two parallel arrows f, g: X → Y is the set Eq(f,g) := {x ∈ X | f(x) = g(x)}.

16. **Definition 2.6.1.1** (Equivalence relations and equivalence classes). Let X be a set. An equivalence relation on X is a subset R ⊆ X × X satisfying reflexivity, symmetry, and transitivity.

17. **Lemma 2.6.1.7** (Generating equivalence relations). Let X be a set and R ⊆ X × X a subset. There exists a smallest equivalence relation S containing R.

18. **Definition 2.6.2.1** (Pushout). The pushout of sets X and Y under a set A via functions f: A → X and g: A → Y is X ⊔_A Y := (X ⊔ Y)/∼ where ∼ identifies f(a) with g(a).

19. **Lemma 2.6.2.8** (Universal property for pushout). For any set Z with functions from X and Y that agree when precomposed from A, there exists a unique function X ⊔_A Y → Z making everything commute.

20. **Definition 2.6.3.1.** The coequalizer of two parallel arrows f, g: X → Y is the quotient of Y by the equivalence relation generated by {(f(x), g(x)) | x ∈ X}.

21. **Definition 2.7.1.1.** Suppose we have f: X → Y and g: Y → X such that g ∘ f = id_X. Then f is a retract section and g is a retract projection.

22. **Notation 2.7.2.1.** Let A and B be sets. We denote the set of functions from A to B by B^A or Hom_Set(A, B).

23. **Proposition 2.7.2.3** (Currying). Let A denote a set. For any sets X, Y there is a bijection Hom(X × A, Y) ≅ Hom(X, Y^A).

24. **Proposition 2.7.3.1.** The following isomorphisms exist for any sets A, B, and C: A + 0 ≅ A, A + B ≅ B + A, (A+B)+C ≅ A+(B+C), A × 0 ≅ 0, A × 1 ≅ A, A × B ≅ B × A, (A×B)×C ≅ A×(B×C), A × (B+C) ≅ (A×B)+(A×C), A^0 ≅ 1, A^1 ≅ A, 0^A ≅ 0 (if A ≠ 0), 1^A ≅ 1, A^(B+C) ≅ A^B × A^C, (A^B)^C ≅ A^(B×C).

25. **Definition 2.7.4.1.** For any set B, define the power set of B, denoted P(B), to be the set of subsets of B.

26. **Definition 2.7.4.4.** Let V be a set and let P(V) be its powerset. A subset X ⊆ P(V) is called downward-closed if, for every u ∈ X and every u' ⊆ u, we have u' ∈ X. We say that X contains all atoms if for every v ∈ V the singleton set {v} is an element of X.

27. **Definition 2.7.4.9.** Define the subobject classifier for Set, denoted Ω, to be the set Ω := {True, False}, together with the function {☉} → Ω sending the unique element to True.

28. **Proposition 2.7.4.10.** Let B be a set. There is an isomorphism P(B) ≅ Hom(B, Ω).

29. **Definition 2.7.4.11** (Characteristic function). Given a subset B' ⊆ B, the corresponding function B → Ω is the characteristic function of B' in B.

30. **Definition 2.7.5.1.** Let f: X → Y be a function. f is surjective if for all y ∈ Y there exists x ∈ X with f(x) = y. f is injective if f(x) = f(x') implies x = x'.

31. **Definition 2.7.5.3** (Monomorphisms, epimorphisms). f: X → Y is a monomorphism if for all g, g': A → X, f ∘ g = f ∘ g' implies g = g'. f is an epimorphism if for all h, h': Y → B, h ∘ f = h' ∘ f implies h = h'.

32. **Proposition 2.7.5.4.** Let f: X → Y be a function. Then f is injective iff it is a monomorphism; f is surjective iff it is an epimorphism.

33. **Proposition 2.7.5.5.** Let f: X → Y be a monomorphism. Then for any function g: A → Y, the top map f': X ×_Y A → A in the pullback diagram is also a monomorphism.

34. **Definition 2.7.6.3.** A multiset is a sequence X := (E, B, π) where E and B are sets and π: E → B is a surjective function.

35. **Definition 2.7.6.7** (Relative set). Let B be a set. A relative set over B is a pair (E, π) with E a set and π: E → B a function.

36. **Definition 2.7.6.12.** Let A be a set. An A-indexed set is a collection of sets S_a, one for each element a ∈ A.

## Chapter 3: Fundamental Considerations in Set

37. **Definition 3.1.1.1** (Monoid). A monoid is a sequence (M, e, ★) where M is a set, e ∈ M is an element, and ★: M × M → M is a function, satisfying identity and associativity laws.

38. **Definition 3.1.1.13.** Let X be a set. A list in X is a pair (n, f) where n ∈ ℕ is a natural number and f: n → X is a function.

39. **Definition 3.1.1.15.** Let X be a set. The free monoid generated by X is (List(X), [], ++).

40. **Definition 3.1.1.17.** A monoid presentation consists of generators and relations.

41. **Definition 3.1.1.24.** A monoid is called cyclic if it has a presentation involving only one generator.

42. **Definition 3.1.2.1** (Monoid action). Let (M, e, ★) be a monoid and S a set. An action of M on S is a function ⊳: M × S → S satisfying identity and associativity laws.

43. **Proposition 3.1.2.11.** Let Σ, S be finite non-empty sets. Giving a function δ: Σ × S → S is equivalent to giving an action of the free monoid List(Σ) on S.

44. **Definition 3.1.4.1.** Let M and M' be monoids. A monoid homomorphism f: M → M' is a function preserving the identity element and the multiplication.

45. **Proposition 3.1.4.5.** Let M = (ℤ, 0, +) and M' = (ℕ, 0, +). The only monoid homomorphism f: M → M' sends every element to 0.

46. **Proposition 3.1.4.9.** Let G be a set, F(G) the free monoid on G, and M any monoid. There is a natural bijection Hom_Mon(F(G), M) ≅ Hom_Set(G, M).

47. **Proposition 3.1.4.12.** Let M, M' be monoids, f: M → M' a monoid homomorphism, S a set, and α an action of M' on S. Then Δ_f(α) is a monoid action of M on S.

48. **Definition 3.2.1.1.** An element m of a monoid has an inverse if there exists m' with mm' = e and m'm = e. A group is a monoid in which every element has an inverse.

49. **Proposition 3.2.1.2.** Suppose M is a monoid and m ∈ M is an element. Then m has at most one inverse.

50. **Definition 3.2.1.9** (Group action). Let (G, e, ★) be a group and S a set. An action of G on S is a function satisfying identity and compatibility laws.

51. **Definition 3.2.1.12.** Let G be a group acting on a set X. For any point x ∈ X, the orbit of x, denoted Gx, is the set {g·x | g ∈ G}.

52. **Definition 3.2.1.16.** Let G and G' be groups. A group homomorphism f: G → G' is a monoid homomorphism.

53. **Definition 3.3.1.1.** A graph G consists of a sequence G := (V, A, src, tgt) where V is a set of vertices, A is a set of arrows, and src, tgt: A → V are functions.

54. **Definition 3.3.2.1.** Let G be a graph. A path of length n in G is a head-to-tail sequence of arrows.

55. **Definition 3.3.3.1.** Let G and G' be graphs. A graph homomorphism f: G → G' consists of functions f₀: V → V' and f₁: A → A' preserving source and target.

56. **Definition 3.3.3.9.** Let X be a set. A binary relation on X is a subset R ⊆ X × X.

57. **Definition 3.4.1.1.** Let S be a set and R ⊆ S × S a binary relation. R is a preorder if it is reflexive and transitive.

58. **Definition 3.4.1.14.** Let (S, ≤) be a preorder. A clique is a subset S' ⊆ S such that for each a, b ∈ S' one has a ≤ b.

59. **Definition 3.4.2.1.** Let (S, ≤) be a preorder and s, t ∈ S. A meet of s and t is an element w satisfying the universal property of greatest lower bound.

60. **Definition 3.4.3.1.** Let S := (S, ≤) be a preorder. The opposite preorder S^op is (S, ≤^op) where s ≤^op s' iff s' ≤ s.

61. **Definition 3.4.4.1.** Let S and S' be preorders. A morphism of preorders f: S → S' is a function preserving the order relation.

62. **Lemma 3.5.2.5.** Suppose G is a graph and ≃ is a congruence on G. If p ≃ q: a → b and r ≃ s: b → c, then pr ≃ qs.

63. **Definition 3.5.2.6.** A database schema (or simply schema) C consists of a pair C := (G, ≃) where G is a graph and ≃ is a congruence on G.

64. **Definition 3.5.3.1.** An instance on a schema C is a functor (PK, FK): C → Set assigning to each vertex a set and to each arrow a function, preserving congruences.

## Chapter 4: Categories and Functors, without Admitting It

65. **Definition 4.1.1.1.** A category C consists of: (A) a collection of objects, (B) for each pair of objects a set of morphisms, (C) identity morphisms, (D) a composition law, satisfying the identity law and the associativity law.

66. **Definition 4.1.1.17.** Let C be a category and X, Y objects. An isomorphism f from X to Y is a morphism f: X → Y with an inverse g: Y → X such that g ∘ f = id_X and f ∘ g = id_Y.

67. **Lemma 4.1.1.21.** Let C be a category and ∼ the relation on Ob(C) given by X ∼ Y iff X and Y are isomorphic. Then ∼ is an equivalence relation.

68. **Definition 4.1.2.1.** Let C and C' be categories. A functor F from C to C' consists of an on-objects part and an on-morphisms part, preserving identities and composition.

69. **Proposition 4.1.2.8** (Preorders to graphs). There is a functor P: PrO → Grph.

70. **Proposition 4.1.2.28.** There exists a category Cat of small categories and functors.

71. **Theorem 4.2.1.3.** There is a functor i: Mon → Cat identifying monoids as one-object categories.

72. **Theorem 4.2.1.6.** There is a functor i: Grp → Cat identifying groups as one-object groupoids.

73. **Proposition 4.2.1.17.** There is a functor i: PrO → Cat identifying preorders as thin categories.

74. **Definition 4.2.3.7.** A groupoid is a category C such that every morphism is an isomorphism.

75. **Definition 4.3.1.2.** Let C and D be categories and F, G: C → D be functors. A natural transformation α from F to G consists of component morphisms α_c: F(c) → G(c) for each object c, satisfying the naturality condition.

76. **Lemma 4.3.1.4.** Naturality squares for natural transformations: if a single naturality square commutes for generators, then all naturality squares commute.

77. **Proposition 4.3.2.2.** Let C and D be categories. There exists a functor category Fun(C, D) whose objects are functors and morphisms are natural transformations.

78. **Notation 4.3.2.3.** We sometimes denote Fun(C, D) by D^C.

79. **Lemma 4.3.2.12.** A natural transformation α: F → G is an isomorphism in Fun(C, D) if and only if α_c is an isomorphism for each c ∈ Ob(C). Such α is called a natural isomorphism.

80. **Definition 4.3.2.16** (Whiskering). Given G₁, G₂: C → D, α: G₁ → G₂, and F: B → C (resp. H: D → E), the whiskered natural transformation α ◇ F (resp. H ◇ α) is defined componentwise.

81. **Definition 4.3.2.17** (Horizontal composition of natural transformations). Given functors F₁, F₂: B → C and G₁, G₂: C → D and natural transformations α: F₁ → F₂ and β: G₁ → G₂, the horizontal composition β ⊙ α: G₁ ∘ F₁ → G₂ ∘ F₂ is defined.

82. **Definition 4.3.3.1.** Let C be a schema (or category). The category of instances on C, denoted C-Set, is Fun(C, Set).

83. **Definition 4.3.4.1** (Equivalence of categories). An equivalence of categories between C and D consists of functors F: C → D and G: D → C with natural isomorphisms F ∘ G ≅ id_D and G ∘ F ≅ id_C.

84. **Definition 4.3.4.8** (Skeleton). An election E in a category C is a choice of one representative from each isomorphism class.

85. **Proposition 4.3.4.9.** Let C be a category and E an election. There is an equivalence of categories between C and its skeleton Sk_E(C).

86. **Definition 4.3.4.10.** A skeleton of C is a category S, equivalent to C, such that for any two objects s, s' ∈ Ob(S), if s ≅ s' then s = s'.

87. **Definition 4.3.4.12.** A functor F: C → D is full if for all c, c' ∈ Ob(C), the function Hom_C(c,c') → Hom_D(F(c),F(c')) is surjective. It is faithful if that function is injective. It is fully faithful if it is both.

88. **Proposition 4.3.4.15.** Let C and C' be categories and F: C → C' an equivalence of categories. Then F is fully faithful.

89. **Definition 4.4.1.2** (Schema morphism). A schema morphism F: C → D between schemas is a graph homomorphism preserving path equivalence classes.

90. **Definition 4.5.1.8.** Let C be a category and X, Y objects. A span on X and Y is (Z, p, q) with p: Z → X and q: Z → Y. A product of X and Y is a span (X × Y, π₁, π₂) with the universal property.

91. **Definition 4.5.1.23.** Let C be a category and X, Y objects. A cospan on X and Y is (Z, i, j) with i: X → Z and j: Y → Z. A coproduct of X and Y is a cospan with the universal property.

92. **Definition 4.5.2.1.** Let C and I be categories. An I-shaped diagram in C is a functor d: I → C.

93. **Definition 4.5.2.6.** Let I be a category. The left cone on I, denoted I◁, adds a cone point -∞ with a unique morphism -∞ → b for each b ∈ Ob(I).

94. **Definition 4.5.2.11.** Let I be a category. The right cone on I, denoted I▷, adds a cone point ∞ with a unique morphism b → ∞ for each b ∈ Ob(I).

95. **Definition 4.5.3.2.** Let C be a category. An object a is initial if for all c there is a unique morphism a → c. An object z is terminal if for all c there is a unique morphism c → z.

96. **Proposition 4.5.3.4.** Let C be a category and a₁, a₂ both be initial objects. Then there is a unique isomorphism a₁ ≅ a₂. Similarly for terminal objects.

97. **Definition 4.5.3.19.** Let C be a category, I an indexing category, X: I → C a diagram. The slice category C_{/X} has as objects the left cones over X and as morphisms natural transformations preserving X. A limit of X is a terminal object in C_{/X}.

98. **Definition 4.5.3.26.** Let C be a category, I an indexing category, X: I → C a diagram. The coslice category C_{X/} has as objects the right cones over X and as morphisms natural transformations preserving X. A colimit of X is an initial object in C_{X/}.

99. **Definition 4.6.1.1.** Let C be a category. The opposite category C^op has the same objects as C with Hom_{C^op}(c,c') := Hom_C(c',c).

100. **Lemma 4.6.1.4.** Let C and D be categories. (C^op)^op = C. Also Fun(C,D) ≅ Fun(C^op, D^op). A functor C^op → D can be identified with a functor C → D^op.

101. **Definition 4.6.2.1.** Let C be a category and J: C → Set a functor. The category of elements of J, denoted ∫_C J, has objects (C, x) with C ∈ Ob(C), x ∈ J(C), and morphisms f: C → C' with J(f)(x) = x'.

102. **Definition 4.6.3.1.** Let C be a category and X ⊆ Ob(C). The full subcategory of C spanned by X has objects X and morphisms Hom_C(x, x').

103. **Definition 4.6.4.1.** Let A, B, C be categories and F: A → C and G: B → C be functors. The comma category (F ↓ G) has objects (a, b, f) with f: F(a) → G(b) and morphisms (q, r) making the relevant squares commute.

104. **Proposition 4.6.5.1.** The following isomorphisms exist for any small categories A, B, and C: A + 0 ≅ A, A + B ≅ B + A, (A+B)+C ≅ A+(B+C), A × 0 ≅ 0, A × 1 ≅ A, A × B ≅ B × A, (A×B)×C ≅ A×(B×C), A × (B+C) ≅ (A×B)+(A×C), A^0 ≅ 1, A^1 ≅ A, 0^A ≅ 0 (if A ≠ 0), 1^A ≅ 1, A^(B+C) ≅ A^B × A^C, (A^B)^C ≅ A^(B×C).

## Chapter 5: Categories at Work

105. **Definition 5.1.1.1.** Let B and A be categories. An adjunction between B and A is a pair of functors L: B → A and R: A → B together with a natural isomorphism Hom_A(L(B), A) ≅ Hom_B(B, R(A)).

106. **Proposition 5.1.1.2.** Let L: Set → Mon be the free monoid functor and R: Mon → Set the forgetful functor. Then L is left adjoint to R.

107. **Proposition 5.1.1.11.** Let C and D be categories, F: C → D a functor, and G, G': D → C functors. If both G and G' are right adjoint to F then there is a natural isomorphism φ: G → G'.

108. **Proposition 5.1.3.1.** Let L ⊣ R be an adjunction. Left adjoints preserve colimits and right adjoints preserve limits.

109. **Notation 5.1.4.1.** Let C be a category. C-Set denotes Fun(C, Set).

110. **Proposition 5.2.1.1.** Let C be a category. The category C-Set is closed under colimits and limits.

111. **Definition 5.2.1.4** (Monomorphism, Epimorphism). Let S be a category and f: X → Y a morphism. f is a monomorphism if f ∘ g = f ∘ g' implies g = g'. f is an epimorphism if h ∘ f = h' ∘ f implies h = h'.

112. **Proposition 5.2.1.5.** Let C be a category and f: X → Y a morphism in C-Set. Then f is a monomorphism (resp. epimorphism) iff for every c ∈ Ob(C), f(c): X(c) → Y(c) is injective (resp. surjective).

113. **Definition 5.2.1.7.** Let C be a category and c ∈ Ob(C). The functor Hom_C(c, -): C → Set is said to be represented by c. A functor F: C → Set isomorphic to Hom_C(c, -) is a representable functor.

114. **Lemma 5.2.1.13** (Yoneda's lemma, part 1). Let C be a category, c ∈ Ob(C), and I: C → Set. There is a natural bijection Hom_{C-Set}(Y_c, I) ≅ I(c).

115. **Lemma 5.2.1.19** (Yoneda's lemma, part 2). Let C be a category. The assignment c ↦ Y_c extends to a functor Y: C^op → C-Set, and this functor is fully faithful.

116. **Definition 5.2.1.23.** Let C be a category, C-Set its category of instances, and 1 the terminal object. A subobject classifier for C-Set is an object Ω_C and a morphism t: 1 → Ω_C such that for any monomorphism f: X → Y there exists a unique char(f): Y → Ω_C making the relevant square a pullback.

117. **Definition 5.2.3.2.** Let X be a topological space. A presheaf on X is a functor O: Open(X)^op → Set.

118. **Definition 5.2.3.5.** Let X be a topological space and O a presheaf. O is a sheaf if it satisfies the sheaf condition: compatible local sections glue uniquely to global sections.

119. **Definition 5.3.2.1** (Monad). A monad on Set consists of a functor T: Set → Set, a unit η: id → T, and a multiplication μ: T ∘ T → T, satisfying the unit laws and associativity law.

120. **Definition 5.3.3.1.** Let T = (T, η, μ) be a monad on Set. The Kleisli category Kls(T) has sets as objects, Hom_{Kls(T)}(X, Y) := Hom_Set(X, T(Y)), with identity given by η and composition via T and μ.

121. **Definition 5.3.5.1.** Let L ⊣ R be an adjunction. The unit η: id_C → R ∘ L is obtained by applying the adjunction isomorphism to id_{L(c)}. The counit ε: L ∘ R → id_D is obtained by applying α⁻¹ to id_{R(d)}.

122. **Proposition 5.3.5.3.** Let C be a category, (T, η, μ) a monad on C, and K := Kls_C(T) the Kleisli category. Then there is an adjunction L ⊣ R with C and K such that the monad is recovered.

123. **Definition 5.4.1.1.** An operad O consists of objects, morphisms (with multiple inputs and one output), identities, and a composition formula, satisfying identity and associativity laws.

124. **Definition 5.4.1.8.** Let O and O' be operads. An operad functor F: O → O' consists of on-objects and on-morphisms parts preserving identities and composition.

125. **Definition 5.4.1.10** (Operad algebra). Let O be an operad. An algebra on O is an operad functor A: O → Sets.

126. **Proposition 5.2.1.21.** For any natural numbers a, b, c, the distributive law (a+b)c = ac + bc holds. (Proved using Yoneda's lemma and category-theoretic reasoning.)
