# All Mathematical Statements: Number Theory II - Class Field Theory

## Statement 1: Theorem 1.1 (Kronecker-Weber)
Every abelian extension of Q is contained in Q(zeta_n) for some n, where zeta_n is a primitive nth root of unity.

## Statement 2: Theorem 1.2 (Hasse Principle)
Let K be a number field, and q(x_1,...,x_n) a quadratic form with coefficients in K. Then for any y in K, q(x_1,...,x_n) = y has a solution if and only if it does in R and in Q_p for all primes p.

## Statement 3: Theorem 1.5 (Main Theorem of LCFT)
For any finite extension K/Q_p, there is a canonical isomorphism Gal^ab(K) = K^x_hat of profinite groups.

## Statement 4: Theorem 1.7 (Main Theorem of GCFT)
For any finite extension F/Q, there is a canonical isomorphism Gal^ab(F) = (A_F^x / F^x)^hat of profinite groups.

## Statement 5: Claim 1.8 (Gal_2 and quadratic characters)
There is a canonical isomorphism Gal_2(K) = (K^x/(K^x)^2)^dual := Hom(K^x/(K^x)^2, Z/2Z) of F_2-vector spaces.

## Statement 6: Claim 1.9 (Self-duality for local fields)
If K is a nonarchimedean local field with char(K) != 2, then K^x/(K^x)^2 = Hom(K^x/(K^x)^2, Z/2Z) canonically.

## Statement 7: Proposition 2.1 (Hilbert symbol properties)
The Hilbert symbol (a,b) for a,b in K^x satisfies: (1) bimultiplicativity: (a,b1*b2) = (a,b1)*(a,b2); (2) (a,1-a) = 1 for all a != 0,1; (3) (a,-a) = 1 for all a != 0.

## Statement 8: Lemma 2.2 (Hilbert symbol symmetry)
(a,b) = (b,a) for all a,b in K^x.

## Statement 9: Proposition 2.3 (K^x/(K^x)^2 for local fields)
For K = Q_p with p odd: K^x/(K^x)^2 = (Z/2Z)^2, generated by p and a nonsquare unit u. For K = Q_2: K^x/(K^x)^2 = (Z/2Z)^3, generated by -1, 2, and 5.

## Statement 10: Claim 2.4 (Hilbert symbol non-degeneracy)
For K a nonarchimedean local field with char != 2, the Hilbert symbol (,): K^x/(K^x)^2 x K^x/(K^x)^2 -> Z/2Z is a non-degenerate bilinear form.

## Statement 11: Claim 2.5 (LCFT for degree 2)
For K a nonarchimedean local field with char != 2, there is a canonical isomorphism Gal^ab(K)/2 = K^x/(K^x)^2.

## Statement 12: Theorem 3.1 (Norm groups for tamely ramified extensions)
Let L/K be a quadratic extension of nonarchimedean local fields with char != 2. Then K^x/NL^x = Z/2Z, and if L/K is unramified, then NL^x = O_K^x * (pi)^{2Z}.

## Statement 13: Proposition 3.2 (Norm surjectivity for units in unramified case)
For L/K unramified quadratic extension, the norm map N: O_L^x -> O_K^x is surjective.

## Statement 14: Claim 3.3 (Kummer theory for quadratic extensions)
For K a field with char != 2, quadratic extensions of K are in bijection with K^x/(K^x)^2, via a -> K(sqrt(a)).

## Statement 15: Claim 3.4 (Norm surjectivity via filtration)
For L/K an unramified extension of local fields, the norm map N: O_L^x -> O_K^x is surjective. This is proved by showing surjectivity at each associated graded level.

## Statement 16: Claim 3.5 (Tame ramification norm group)
If L/K is a tamely ramified quadratic extension with L = K(sqrt(u*pi)), then NL^x = <u> * (O_K^x)^2 * pi^{2Z}, where <u> is the subgroup generated by u.

## Statement 17: Theorem 4.1 (Quadratic Hilbert Reciprocity)
For a,b in Q^x, the product of (a,b)_v over all places v of Q (including infinity) equals 1.

## Statement 18: Proposition 4.2 (Product formula)
For any x in Q^x, the product of |x|_v over all places v of Q equals 1.

## Statement 19: Theorem 4.3 (Quadratic Reciprocity via Hilbert symbols)
Let p and q be distinct odd primes. Then the Legendre symbol (p/q)(q/p) = (-1)^{(p-1)(q-1)/4}.

## Statement 20: Proposition 4.4 (Gauss sum squared)
For chi a primitive character mod p (p odd prime) and psi the standard additive character on Z/pZ, the Gauss sum G_{chi,psi}^2 = chi(-1)*p.

## Statement 21: Proposition 5.1 (Non-degeneracy of adele pairing)
The pairing A_F x F -> Q/Z (for a number field F) given by (x, alpha) -> sum_v Tr_{F_v/Q_p}(x_v * alpha) is non-degenerate, i.e., F = {x in A_F : <x, alpha> = 0 for all alpha in F}.

## Statement 22: Proposition 5.2 (K^x/(K^x)^2 computation for Q_p)
For K = Q_p with p odd, #(K^x/(K^x)^2) = 4. For K = Q_2, #(K^x/(K^x)^2) = 8. For K = R, #(K^x/(K^x)^2) = 2.

## Statement 23: Corollary 5.3 (Product formula for Hilbert symbols)
For a,b in Q^x, the product of Hilbert symbols prod_v (a,b)_v = 1.

## Statement 24: Proposition 5.4 (Exactness of Q^x -> prod K_v^x/(K_v^x)^2)
The sequence Q^x -> prod_v Q_v^x/(Q_v^x)^2 -> Z/2Z -> 0 is exact, where the second map is the product of Hilbert symbols.

## Statement 25: Claim 5.5 (Classification of Hamiltonian algebras over Q)
Over Q, H_{a,b} = M_2(Q) if and only if (a,b)_v = 1 for all places v. The Hamiltonian algebra is determined by its local invariants.

## Statement 26: Theorem 6.1 (Torsion exact sequence)
If 0 -> A -f-> B -g-> C -> 0 is a short exact sequence of abelian groups with A, B, C being n-torsion, then there is a long exact sequence involving A[n], B[n], C[n], A/nA, B/nB, C/nB.

## Statement 27: Proposition 6.2 (Euler characteristic multiplicativity)
If 0 -> A -> B -> C -> 0 is exact with each having finite Euler characteristic, then chi(B) = chi(A) * chi(C).

## Statement 28: Proposition 6.3 (Norm map structure for local fields)
Let G be a cyclic group of order n acting on L^x. Then #H^0_hat(G, L^x) = n for L/K a cyclic extension of local fields.

## Statement 29: Claim 6.4 (Filtration and Herbrand quotient for O_L^x)
For a cyclic extension L/K of local fields, chi(O_L^x) = 1 where chi is the Herbrand quotient.

## Statement 30: Theorem 7.1 (Long exact sequence on Tate cohomology)
For G a cyclic group and 0 -> A -> B -> C -> 0 a short exact sequence of G-modules, there is a long exact sequence: ... -> H^0_hat(A) -> H^0_hat(B) -> H^0_hat(C) -> H^1_hat(A) -> H^1_hat(B) -> H^1_hat(C) -> H^0_hat(A) -> ...

## Statement 31: Proposition 7.2 (Herbrand quotient of finite modules)
If M is a finite G-module (G cyclic), then chi(M) = 1.

## Statement 32: Proposition 7.3 (Herbrand quotient multiplicativity)
If 0 -> A -> B -> C -> 0 is a short exact sequence of G-modules (G cyclic) and two of the three Herbrand quotients are defined, then the third is too and chi(B) = chi(A) * chi(C).

## Statement 33: Claim 7.4 (Herbrand quotient of Z)
For G = Z/nZ acting trivially on Z, chi(Z) = n.

## Statement 34: Claim 7.5 (Herbrand quotient of O_K^x)
For L/K a degree-n cyclic extension of local fields, chi(O_L^x) = 1.

## Statement 35: Claim 7.6 (Herbrand quotient computation for totally ramified)
For L/K a totally ramified cyclic extension, chi(O_L) = 1/n (as ratios) via the filtration by powers of the maximal ideal.

## Statement 36: Claim 7.7 (Herbrand quotient of L^x)
For L/K a degree-n cyclic extension of local fields, chi(L^x) = n.

## Statement 37: Claim 7.8 (Properties of norms for local fields)
(1) H^0_hat(Z/nZ, Z) = Z/nZ; (2) N: O_L^x -> O_K^x is surjective for unramified L/K; (3) #(K^x/NL^x) = n for cyclic L/K of degree n.

## Statement 38: Theorem 8.1 (Group ring characterization)
The group ring R[G] of a cyclic group G = Z/nZ generated by sigma is isomorphic to Z[x]/(x^n - 1) via sigma -> x.

## Statement 39: Claim 8.2 (G-module structure via group ring)
A G-module is equivalently a module over the group ring Z[G]. The augmentation map epsilon: Z[G] -> Z sends every g to 1.

## Statement 40: Proposition 8.3 (Relation between H^1_hat and quotient)
For a cyclic group G = <sigma> acting on A: H^1_hat(G,A) = ker(N)/(sigma-1)A and H^0_hat(G,A) = A^G/N(A).

## Statement 41: Claim 8.4 (Inverse limit construction)
Let 0 -> A_i -> B_i -> C_i -> 0 be an inverse system of short exact sequences of abelian groups. If each A_i -> A_{i-1} is surjective, then 0 -> lim A_i -> lim B_i -> lim C_i -> 0 is exact.

## Statement 42: Corollary 8.5 (Inverse limit exact sequence, Mittag-Leffler)
If the transition maps in an inverse system of short exact sequences satisfy the Mittag-Leffler condition, then the inverse limit sequence is exact.

## Statement 43: Theorem 9.1 (Hilbert's Theorem 90)
For a finite Galois extension L/K with G = Gal(L/K), H^1(G, L^x) = 0.

## Statement 44: Theorem 9.2 (Additive Hilbert 90)
For a finite Galois extension L/K with cyclic Galois group G, H^1(G, L) = 0 (and more generally for all n >= 1).

## Statement 45: Proposition 9.3 (Hilbert 90 via cocycles)
Every 1-cocycle G -> L^x is a 1-coboundary, i.e., for every map f: G -> L^x satisfying f(gh) = f(g) * g(f(h)), there exists beta in L^x with f(g) = g(beta)/beta.

## Statement 46: Claim 10.1 (Cone construction)
For a morphism f: X -> Y of chain complexes, the cone Cone(f) fits into an exact triangle X -> Y -> Cone(f) -> X[1].

## Statement 47: Claim 10.2 (Long exact sequence on cohomology)
A short exact sequence 0 -> X -> Y -> Z -> 0 of chain complexes induces a long exact sequence on cohomology: ... -> H^i(X) -> H^i(Y) -> H^i(Z) -> H^{i+1}(X) -> ...

## Statement 48: Claim 10.3 (Quasi-isomorphism characterization)
A morphism f: X -> Y is a quasi-isomorphism if and only if Cone(f) is acyclic.

## Statement 49: Claim 10.4 (Homotopy equivalence implies quasi-isomorphism)
If f: X -> Y is a homotopy equivalence of chain complexes, then f is a quasi-isomorphism.

## Statement 50: Claim 10.5 (Coinvariants as quotient)
For a G-module A, A_G = A/I_G*A where I_G = ker(epsilon: Z[G] -> Z) is the augmentation ideal.

## Statement 51: Claim 10.6 (Invariants and coinvariants agree for trivial action)
For trivial G-action on A: A^G = A and A_G = A.

## Statement 52: Claim 10.7 (Two-term complex coinvariants)
For a two-term complex X = [A -> B] of G-modules, X_G = [A_G -> B_G].

## Statement 53: Claim 10.12 (Four-term exact sequence and homotopy cokernel)
A four-term exact sequence 0 -> A -> B -> C -> D -> 0 yields a quasi-isomorphism between the homotopy cokernel of [A -> B] -> [C -> D] and D.

## Statement 54: Proposition 11.1 (Mapping complex and Ext)
For chain complexes X and Y, the cohomology of the mapping complex Hom(X,Y) computes Ext groups: H^i(Hom(X,Y)) = Ext^i(X,Y).

## Statement 55: Proposition 11.2 (Projective modules and Ext vanishing)
A module P is projective if and only if Ext^i(P, -) = 0 for all i >= 1. Equivalently, every surjection onto P splits.

## Statement 56: Proposition 11.3 (Projective resolution existence)
Every module M admits a projective resolution, i.e., a quasi-isomorphism P -> M from a complex of projective modules.

## Statement 57: Proposition 11.4 (Derived Hom well-defined)
The derived mapping complex RHom(X,Y) = Hom(P,Y), where P -> X is a projective resolution, is well-defined up to quasi-isomorphism.

## Statement 58: Claim 11.5 (Group cohomology via derived functors)
Group cohomology H^i(G, M) = Ext^i_{Z[G]}(Z, M) = H^i(Hom_G(P, M)) where P -> Z is a projective resolution of Z as a Z[G]-module.

## Statement 59: Claim 11.6 (Inflation and restriction maps)
For H a normal subgroup of G, there are natural restriction maps H^i(G, M) -> H^i(H, M) and inflation maps H^i(G/H, M^H) -> H^i(G, M).

## Statement 60: Claim 12.1 (Bar resolution)
The bar complex Bar_G is a projective resolution of Z as a Z[G]-module, with Bar_G^{-n} = Z[G^{n+1}] as free Z[G]-modules.

## Statement 61: Claim 12.2 (Cocycle description of H^1)
H^1(G, M) = {1-cocycles} / {1-coboundaries}, where a 1-cocycle is f: G -> M with f(gh) = f(g) + g*f(h), and a 1-coboundary is f(g) = g*m - m for some m.

## Statement 62: Claim 12.3 (Cocycle description of H^2)
H^2(G, M) is represented by 2-cocycles phi: G x G -> M satisfying g1*phi(g2,g3) + phi(g1,g2*g3) = phi(g1*g2,g3) + phi(g1,g2), modulo 2-coboundaries.

## Statement 63: Claim 12.4 (Trivial action H^1)
If G acts trivially on M, then H^1(G, M) = Hom(G, M).

## Statement 64: Claim 12.5 (Hilbert 90 reproved)
H^1(G, L^x) = 0 for a finite Galois extension L/K with G = Gal(L/K), proved via the bar resolution.

## Statement 65: Proposition 13.1 (Tensor product of complexes)
The tensor product X tensor_{Z[G]} Y of two complexes of G-modules is well-defined and preserves quasi-isomorphisms when one factor is projective.

## Statement 66: Proposition 13.2 (Homotopy coinvariants via tensor product)
X_{hG} = X tensor_{Z[G]} P_G, where P_G -> Z is a projective resolution.

## Statement 67: Proposition 13.3 (Group homology)
H_i(G, X) = H^{-i}(X_{hG}) is group homology. For a module M in degree 0: H_0(G, M) = M_G.

## Statement 68: Claim 13.4 (H_1(G,Z) = G^{ab})
H_1(G, Z) = G^{ab}, the abelianization of G.

## Statement 69: Claim 13.5 (I_G/I_G^2 = G^{ab})
The augmentation ideal quotient I_G/I_G^2 is isomorphic to G^{ab}, via the map g -> [g] - 1 mod I_G^2.

## Statement 70: Claim 13.13 (Cohomological LCFT)
For a finite group G and extension L/K of local fields, P_G -> L^x[2] is an isomorphism on Tate cohomology, giving H^{-2}(G, Z) = K^x/N(L^x) = G^{ab}.

## Statement 71: Proposition 14.1 (Tate cohomology for modules)
Let M be a G-module. Then: (1) H_hat^i(G,M) = H^i(G,M) for i >= 1; (2) H_hat^0(G,M) = M^G/N(M); (3) H_hat^{-1}(G,M) = ker(N)/(g-1) = ker(N: M_G -> M); (4) H_hat^{-i}(G,M) = H_{i-1}(G,M) for i >= 2.

## Statement 72: Theorem 14.2 (Main Theorem of Cohomological LCFT)
Let L/K be an extension of nonarchimedean local fields with finite Galois group G. Then (L^x)^{tG} = (Z[-2])^{tG}.

## Statement 73: Claim 14.6 (Exactness of K^{unr} sequence)
The sequence 1 -> K^x -> K^{unr,x} -> K^{unr,x} -> Z -> 0, where the middle map is x -> x/sigma(x), is exact.

## Statement 74: Claim 15.1 (Algebraic elements of K^{unr} are unramified)
If x in K^{unr} is algebraic over K, then K' := K(x) is unramified over K.

## Statement 75: Claim 15.2 (Fixed points of Frobenius)
(K^{unr})^{sigma=1} = K, the elements fixed by the Frobenius automorphism sigma are exactly K.

## Statement 76: Theorem 15.3 (Vanishing Theorem, totally ramified case)
If L/K is totally ramified, then the complex (L^{unr,x})^{tG} is acyclic.

## Statement 77: Claim 15.4 (Vanishing theorem implies cohomological LCFT)
The vanishing theorem implies (L^x)^{tG} = Z^{tG}[-2], which is the main theorem of cohomological LCFT.

## Statement 78: Theorem 15.5 (General Vanishing Theorem)
[(L tensor_K K^{unr})^x]^{tG} is acyclic, for any finite Galois extension L/K.

## Statement 79: Claim 15.6 (General exact sequence)
The sequence 1 -> L^x -> (L tensor_K K^{unr})^x -> (L tensor_K K^{unr})^x -> Z -> 0 is exact, where the middle map is x -> x/sigma(x).

## Statement 80: Theorem 16.1 (Tate cohomology vanishing for cyclic groups)
For a cyclic group G, X^{tG} is acyclic if and only if H_hat^0(G,X) = 0 = H_hat^1(G,X).

## Statement 81: Theorem 16.2 (Tate cohomology vanishing for p-groups)
Theorem 16.1 holds also if G is a p-group: if H_hat^0(G,X) = 0 = H_hat^1(G,X), then X^{tG} is acyclic.

## Statement 82: Theorem 16.3 (Tate cohomology vanishing criterion)
If for every prime p and every p-Sylow subgroup G_p of G, H_hat^0(G_p, X) = 0 = H_hat^1(G_p, X), then X^{tG} is acyclic.

## Statement 83: Proposition 16.5 (Vanishing for F_p[G]-modules)
Let X be a complex of F_p[G]-modules (G a p-group). If H_hat^0(G,X) = 0, then X^{tG} is acyclic.

## Statement 84: Lemma 16.6 (Fixed points of p-group representations)
Let V be a non-zero F_p[G]-module (G a p-group). Then V^G != 0.

## Statement 85: Proposition 17.1 (Structure of p-groups)
Let G be an l-group. Then there is a chain of normal subgroups 1 <| G_0 <| ... <| G_m = G such that G_{i+1}/G_i is cyclic for all i.

## Statement 86: Claim 17.2 (Elements become norms in unramified extensions)
Let G be cyclic of order n, L/K totally ramified. Let x in K^x. Then x is in the image of N: L_m^x -> K_m^x for m sufficiently large (where K_m is the degree-m unramified extension of K).

## Statement 87: Lemma 17.3 (Vanishing by normal subgroup)
Let X be a complex of G-modules, and 1 -> H -> G -> G/H -> 1 exact. If X^{tH} = 0 and (X^{hH})^{tG/H} = 0, then X^{tG} = 0.

## Statement 88: Theorem 18.2 (Existence Theorem)
A subgroup Gamma of K^x is a norm group if and only if Gamma is closed and of finite index.

## Statement 89: Lemma 18.4 (Norm subgroups are closed and finite-index)
If Gamma is a norm subgroup of K^x, then Gamma is closed and of finite index.

## Statement 90: Lemma 18.5 (Norm subgroups are upward closed)
If Gamma' is a subgroup of K^x with K^x >= Gamma' >= Gamma for a norm subgroup Gamma, then Gamma' is a norm subgroup as well.

## Statement 91: Claim 18.6 (Order of Hom for n-torsion groups)
Let A be an n-torsion finite abelian group. Then #A = #Hom(A, Z/nZ).

## Statement 92: Corollary 18.7 ((K^x)^n is a norm subgroup)
If mu_n is contained in K, then (K^x)^n is a norm subgroup.

## Statement 93: Claim 18.12 (Acyclicity preserved by homotopy invariants)
If X is acyclic and bounded below, then X^{hG} is acyclic for profinite G.

## Statement 94: Proposition 18.13 (Infinite Hilbert 90)
If L/K is a (possibly infinite) G-Galois extension, then H^1(G, L^x) = 0.

## Statement 95: Corollary 18.14 (Kummer theory via cohomology)
Let G = Gal(K_bar/K) and n prime to char(K). If mu_n is in K, then K^x/(K^x)^n = Hom_{cts}(G, mu_n).

## Statement 96: Corollary 19.5 (Brauer group of local fields)
For a nonarchimedean local field K, Br^{coh}(K) = Q/Z.

## Statement 97: Proposition 19.7 (CSA characterization)
Let K be a field and A a finite-dimensional K-algebra with center K. Then TFAE: (1) A is simple; (2) A tensor_K L = M_n(L) for some separable L/K; (3) A = M_n(D) for some central division algebra D.

## Statement 98: Corollary 19.8 (CSA dimension is a square)
Any central simple algebra over K has dimension a perfect square.

## Statement 99: Proposition 19.12 (Tensor product of CSAs)
If A and B are CSAs over K, then A tensor_K B is also a CSA. This gives Br^{csa}(K) the structure of an abelian group.

## Statement 100: Claim 19.15 (Splitting field embeds in division algebra)
An n^2-dimensional central division algebra D/K splits over a degree-n extension L/K if and only if K is contained in L is contained in D as a subalgebra.

## Statement 101: Theorem 19.16 (Cohomological = CSA Brauer group)
For every Galois extension L/K, Br^{coh}(K) = Br^{csa}(K) and Br^{coh}(K/L) = Br^{csa}(K/L).

## Statement 102: Claim 19.17 (Number of division algebras)
There are phi(n) = #(Z/nZ)^x isomorphism classes of central division algebras over K of degree n^2.

## Statement 103: Claim 19.18 (Brauer group functoriality)
For a degree-n extension L/K of nonarchimedean local fields, the diagram Br(K) -> Br(L) and Q/Z -> Q/Z (multiplication by n) commutes.

## Statement 104: Corollary 19.19 (Splitting over degree-n extensions)
Any degree-n^2 division algebra splits over any degree-n extension of K.

## Statement 105: Corollary 19.20 (Division algebra contains all degree-n fields)
Any degree-n^2 central division algebra over K contains every degree-n field extension of K.

## Statement 106: Claim 20.1 (Brauer group exact sequence)
There is an exact sequence 0 -> Br^{coh}(K/L) -> Br^{coh}(K) -> Br^{coh}(L).

## Statement 107: Lemma 20.3 (Truncation and cohomology)
The identity map tau^{<=n}X -> X is a map of complexes, and H^i(tau^{<=n}X) -> H^i(X) is an isomorphism for all i <= n.

## Statement 108: Corollary 20.4 (Truncation preserves quasi-isomorphism)
If X -> Y is a quasi-isomorphism, then tau^{<=n}X -> tau^{<=n}Y is also a quasi-isomorphism.

## Statement 109: Lemma 20.7 (Lower truncation and cohomology)
H^i(X) -> H^i(tau^{>=n+1}X) is an isomorphism for all i >= n+1.

## Statement 110: Theorem 20.8 (Main Theorems of GCFT, restated)
For a global field F: Gal^{ab}(F) = (A_F^x / F^x)^hat, and for finite Galois E/F: Gal(E/F)^{ab} = N(A_E^x) \ A_F^x / F^x.

## Statement 111: Theorem 20.9 (Inequalities of GCFT)
(1) For E/F a degree-n cyclic extension of global fields, chi(C_E) = n. (2) For all finite G-Galois extensions E/F, H^1(G, C_E) = 0.

## Statement 112: Claim 20.10 (Cohomology of adeles)
For a G-Galois extension E/F of global fields, H_hat^i(G, A_E^x) = direct_sum_{v in M_F} H_hat^i(G, (E tensor_F F_v)^x).

## Statement 113: Lemma 20.12 (S-adeles generate)
There exists a finite S subset of M_F with A_{F,S}^x * F^x = A_F^x.

## Statement 114: Claim 20.13 (S-units exact sequence)
There is a short exact sequence 0 -> E_S^x -> A_{E,S}^x -> C_E -> 0, where E_S^x = E^x intersect A_{E,S}^x.

## Statement 115: Lemma 20.14 (Herbrand quotient of lattices)
If a cyclic group G acts on an R-vector space V, and Lambda_1, Lambda_2 are two G-fixed lattices in V, then chi(Lambda_1) = chi(Lambda_2).

## Statement 116: Lemma 21.1 (Module isomorphism after extension)
Let L/K be an extension of infinite fields, A a K-algebra, M and N two A-modules finite-dimensional over K with M projective over A. If M tensor_K L = N tensor_K L as A tensor_K L-modules, then M = N.

## Statement 117: Theorem 21.2 (Local Kronecker-Weber for Q_p)
Q_p^{ab} = [union_{n>=0} Q_p(zeta_{p^n})] * Q_p^{unr}.

## Statement 118: Lemma 21.3 (Surjective endomorphisms of profinite groups)
Let G be a profinite group such that for all n > 0, the number of open subgroups of index n is finite. Then every continuous surjective homomorphism phi: G -> G is an isomorphism.

## Statement 119: Theorem 21.4 (Dwork, Lubin-Tate)
(1) p in Q_p^x acts trivially on union Q_p(zeta_{p^n}) and as the Frobenius on Q_p^{unr}. (2) x in Z_p^x acts trivially on Q_p^{unr} and by x^{-1} on union Q_p(zeta_{p^n}).

## Statement 120: Claim 21.5 (LCFT gives Artin map)
LCFT gives a map theta: A_F^x -> G with theta(N(A_E^x)) = 1, defined as the product of local Artin maps.

## Statement 121: Theorem 21.6 (Artin Reciprocity)
theta(F^x) = 1, hence theta gives a map C_F/N(C_E) -> G.

## Statement 122: Theorem 21.8 (Brauer Reciprocity)
The composition Br(F/E) -> H^2(G, A_E^x) -> Q/Z is zero for all E/F.

## Statement 123: Claim 21.10 (Artin reciprocity for cyclotomic extensions)
Artin reciprocity is valid for Q(zeta_n)/Q.

## Statement 124: Claim 22.1 (Artin = Brauer reciprocity for cyclic)
For E/F a cyclic extension of global fields, Artin reciprocity is equivalent to Brauer reciprocity.

## Statement 125: Claim 22.2 (Splitting by cyclic cyclotomic extensions)
For any global field F and every beta in Br(F), there exists a cyclic cyclotomic extension E/F such that beta in Br(F/E).

## Statement 126: Theorem 22.3 (Second inequality / H^1 vanishing)
For all extensions E/F of global fields, H^1(G, C_E) = 0.

## Statement 127: Corollary 22.4 (Injection of Brauer groups)
For any global field F, there is a canonical injection Br(F) -> direct_sum_{v in M_F} Br(F_v).

## Statement 128: Claim 22.5 (Existence of cyclic cyclotomic extensions)
Given a finite set of places S of a global field F, and positive integers m_v for v in S, there exists a cyclic cyclotomic extension E/F such that [E_w:F_v] is divisible by m_v.

## Statement 129: Claim 23.1 (S-units and local pth powers)
u in O_{F,S}^x is a pth power if and only if its image in F_v^x is a pth power for each v in S.

## Statement 130: Claim 23.2 (S-units intersection with Gamma)
O_{F,S}^x intersect Gamma = (O_{F,S}^x)^p, where Gamma = prod_{v in S} (F_v^x)^p x prod_{v not in S} O_{F_v}^x.

## Statement 131: Claim 23.3 (Gamma contained in norm group)
Gamma is contained in N(A_E^x).

## Statement 132: Claim 23.4 (Existence of auxiliary set T)
Given S subset M_F, there exists T subset M_F with #T = #S - 1, S intersect T empty, every v in T split in E, and the strengthened local-global criterion for pth powers.

## Statement 133: Claim 23.5 (Enlarged Gamma in norm group)
With T as in Claim 23.4, the enlarged Gamma is contained in N(A_E^x).

## Statement 134: Claim 23.6 (Frobenius elements generate)
For any abelian extension F'/F of global fields, the Frobenius elements for v not in S generate Gal(F'/F).

## Statement 135: Claim 23.7 (Galois group of S-unit extension)
Gal(F'/F) = (Z/pZ)^{#S}, where F' = F({p-th root of u : u in O_{F,S}^x}).

## Statement 136: Claim 23.8 (Places in T are split)
Each v in T is split in E.

## Statement 137: Claim 23.9 (Refined pth power criterion)
An element x in O_{F,S union T}^x is a pth power if and only if x in (F_v^x)^p for every v in S.

## Statement 138: Claim 23.10 (Reduction of second inequality)
If the second inequality holds for any cyclic order-p extension for which the base field contains a pth root of unity, then it holds for any cyclic order-p extension.

## Statement 139: Claim 23.11 (General reduction of second inequality)
If the second inequality holds for any cyclic order-p extension of number fields, then it holds for any extension.

## Statement 140: Claim 19.4 (Compatibility of Brauer group maps)
Under LCFT, the diagram relating H^2(G_2, L_1^x) -> H^2(G_1, L_1^x) and the fractional parts of Z commutes.

## Statement 141: Corollary 19.19 restated (Any n^2-division algebra splits over degree n)
Any degree-n^2 division algebra splits over any degree-n extension of a nonarchimedean local field K.
